# Smart Digital Tailoring System

## Run
1. Extract this ZIP.
2. Open terminal in the folder containing package.json.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Vite.

## Included workflow
### Customer
Login -> Dashboard -> Profile -> Measurements -> Browse Designs -> Customize Dress -> Cart -> Demo Payment -> Orders -> Tracking -> Offers -> Settings.

### Tailor/Admin
Login -> Dashboard -> Add Customers -> Review Measurements -> Manage Orders/Status -> Categories -> Workload -> Revenue & Reports.

## React hooks
useState, useEffect, useContext, useRef, useMemo, useCallback.

## Storage
Customer profile, measurements, cart, customers, orders and session are stored in browser LocalStorage. No backend is required for this demo.
